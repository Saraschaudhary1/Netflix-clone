# Netflix India Landing Page Clone

A responsive front-end recreation of the Netflix India landing page built using **HTML5 and CSS3**. This project replicates the visual layout of a popular streaming platform, focusing on clean structure, modern styling, and responsive design.

## Overview

The project was created as a front-end development practice project to strengthen my understanding of HTML and CSS. It recreates key sections of the Netflix India homepage, including the hero section, streaming feature highlights, frequently asked questions, and footer.

## Features

- **Hero Section:** Netflix-inspired background, headline, email input field, and call-to-action buttons.
- **Navigation Bar:** Logo placement and language selection and sign-in buttons.
- **Feature Sections:** Highlights streaming features such as watching on TV, downloading shows, streaming across devices, and creating profiles for kids.
- **FAQ Section:** Frequently asked questions presented in a clean, organized layout with hover effects.
- **Footer:** Structured navigation links arranged in multiple columns.
- **Responsive Design:** CSS media queries help adapt layouts to different screen sizes.
- **Interactive Styling:** Hover effects and transitions enhance the visual experience.

## Technologies Used

- **HTML5** — For page structure and semantic organization.
- **CSS3** — For styling, layouts, and visual presentation.
- **Flexbox** — For alignment and flexible component layouts.
- **CSS Grid** — For organizing footer content.
- **Media Queries** — For responsive styling across screen sizes.
- **Transitions** — For smooth hover effects.

## What I Learned

Through this project, I practiced building structured web pages, positioning elements, working with background images, and creating layouts using Flexbox and CSS Grid. I also gained experience with CSS transitions, responsive design, and organizing page sections for a consistent user experience.

## Project Structure

- `index.html` — Contains the structure and content of the landing page.
- `style.css` — Contains the styling, layout rules, responsive adjustments, and visual effects.
- Image and logo assets — Used for the background, branding, and streaming feature sections.
